# HiAscend 积分明细聚合油猴插件

安装 [油猴脚本](https://raw.githubusercontent.com/KaranocaVe/hiascend-rewards-aggregator/main/hiascend-rewards-aggregator.user.js) 后，打开 [昇腾社区积分兑换](https://www.hiascend.com/developer/rewards)，点击“积分明细”即可自动处理。

插件读取“全部 / 获得 / 支出”当前标签页的所有分页，**第一页返回后立即展示汇总**；后续每一页请求完成后，都会独立更新已加载条数、分页进度、各日期积分及合并项数，不需要等待其他并发请求或全部数据返回。最多同时读取四页。

同一日期下，按描述和收支方向合并同类项目并累计积分；`×N` 表示原始记录数。日期按新到旧排序，初始折叠。加载期间仍可展开、折叠日期，后续数据更新不会重置展开状态。顶部提供“全部展开”“全部折叠”“重新加载”和“原始明细”。切换标签页会保留已加载的结果，重新加载会取消对应标签页的旧请求并从第一页重新统计。

脚本只匹配 `www.hiascend.com/developer/rewards` 页面，不修改服务端数据。若未登录、接口权限错误或部分分页失败，面板会显示错误并提供重新加载按钮；已经成功读取的分页汇总会保留在面板上。
