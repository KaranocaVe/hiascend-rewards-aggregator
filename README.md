# HiAscend 积分明细聚合

安装 [油猴脚本](https://raw.githubusercontent.com/KaranocaVe/hiascend-rewards-aggregator/main/hiascend-rewards-aggregator.user.js) 后，打开[昇腾社区积分兑换](https://www.hiascend.com/developer/rewards)，登录并点击“积分明细”。插件沿用站点的积分弹窗、标签、按钮样式和 OUI 主题。

- **积分概览**显示站点可用积分、30 天内预计失效积分和最近一批到期倒计时。展开到期表可查看每个批次预计剩余和已抵扣的积分。
- **积分组成**按来源绘制饼图，可在当前余额估算和历史获得之间切换。**月度积分收入**以柱状图显示，可查看近 12 个月或全部月份。历史获得和收入均排除兑换返还。
- **日期明细**按日期、描述和收支方向聚合。日期默认折叠，`×N` 表示合并了 N 条流水。“全部 / 获得 / 支出”复用同一份完整流水，“原始明细”可恢复站点的明细列表。

## 到期计算

脚本等全部分页加载完成后再计算。按[昇腾开发者计划](https://www.hiascend.com/developer-program)的规则，有效期从获取月起算一年。例如，北京时间 2026 年 11 月获取的积分按 2027 年 11 月 1 日起失效计算。

公开规则未说明兑换时的批次扣减顺序。插件按流水发生时间重放，估算先抵扣当时仍有效且最早到期的积分。只有日期的同日流水沿用接口最新在前的顺序倒放。已失效批次退出可用余额，流水中的到期扣减用于核对，避免重复抵扣。能唯一关联到原支出的一笔全额兑换返还恢复相应原始批次的有效部分。

站点余额可读取时，脚本会核对估算合计。遇到对账差异、无法匹配的返还或不完整流水时，界面会提示原因并暂停显示到期预测。脚本使用当前登录态读取数据，所有计算在浏览器内完成。
