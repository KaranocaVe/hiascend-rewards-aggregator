# HiAscend 积分明细聚合油猴插件

安装 `hiascend-rewards-aggregator.user.js` 后，打开 [昇腾社区积分兑换](https://www.hiascend.com/developer/rewards)，点击“积分明细”即可自动处理。

插件会使用当前页面的登录态加载“全部 / 获得 / 支出”当前标签页的所有分页，然后按“日期 + 描述 + 收支方向”聚合。同一日期下的同类记录合并为一行，积分显示合计，`×N` 表示合并了 N 条原始记录；日期默认按最新日期展开，其余日期折叠。顶部提供“全部展开”“全部折叠”“重新加载”和“原始明细”。

脚本只匹配 `www.hiascend.com/developer/rewards` 页面，不修改服务端数据。若未登录或接口返回权限错误，面板会显示错误并提供重试按钮。
